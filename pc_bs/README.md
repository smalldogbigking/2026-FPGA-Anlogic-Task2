# 安路视界 V3 fixed B/S · 3.0.2

双击外层启动BS服务器.bat或本目录run.bat。默认8768，其他项目占用时自动选空闲端口，只复用本目录且版本相同的实例。同目录旧服务会提示先关闭原窗口再重启，不会悄悄继续使用旧进程。公网映射由用户自行配置，服务不启动隧道。

原USB视频/控制保持921600。拍照、手动录像、人脸出现录像、消失5秒后保存、事件数据库和历史文件保留。SORT扫脸阶段自动获取预览，确认阶段保存对应PNG和事件缩略图；失败不伪造成功。

/sort为分拣工作台。额外串口可选择FPGA视觉快照或MCU JSON事件，115200。视觉口读取四目标、源帧、序号与CRC，MCU口记录开始/完成/故障。标定方形3不触发异常消息。旧协议2/3/4与新协议5均可解析，SORT新字段只在协议5下解释。

原模式3棕褐已在V3移除，界面显示原图备用。网页Android下载由同级android/releases/release.json选择当前3.0.2安装包（versionCode 6）。电脑配置现支持USB协议5，SORT需要协议5。手机连接标识为plus_v3_sort_app，不再使用旧V2标识。

测试：python -m unittest discover -s tests -v；node --check static/app.js。测试使用隔离数据，不连接实际串口。运行数据默认captures/，可设置FPGA_CAPTURE_DIR。用户最新STM32固件未启用MCU电脑输出，本服务不假设其已有机械臂事件上传；完整视觉坐标仍需独立视觉串口。
