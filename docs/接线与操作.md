# 接线与操作

## FPGA与STM32

|用途|FPGA开发板位置|连接STM32|
|---|---|---|
|目标数据串口TX|GPIOA6，芯片T2，GPIOA排针J1第7脚|PB11 / USART3_RX|
|共地|GPIOA排针J1第12或28脚GND|GND|
|原摄像头水平PWM|GPIOA1，芯片V1，J1第2脚|原水平舵机|
|原摄像头俯仰PWM|GPIOA2，芯片U2，J1第3脚|原俯仰舵机|

视觉UART为3.3V TTL、115200、8N1，仅FPGA发送、STM32接收。FPGA原USB口继续连接电脑用于预览和控制，与GPIOA6的机械臂串口分开。

## 机械臂与OLED

|用途|STM32引脚|
|---|---|
|CH1夹爪，开1000/闭1500μs|PA0 / TIM2_CH1|
|CH2，固定1382μs|PA1 / TIM2_CH2|
|CH3|PA2 / TIM2_CH3|
|CH4|PA3 / TIM2_CH4|
|CH5大臂|PA6 / TIM3_CH1|
|CH6底座|PA7 / TIM3_CH2|
|SSD1306 SCL/SDA|PB6 / PB7，I²C地址0x3C|
|OLED电源|3.3V、GND|
|可选暂停|PB12接GND锁定暂停，RESET恢复|
|ST-Link SWD|PA13 SWDIO、PA14 SWCLK、GND|

舵机使用原独立供电并共地。PA9、PA10、PB10不占用，无STM32电脑测试串口。STM32 PA6已被CH5使用，FPGA TX应接PB11。

## 上板流程

1. FPGA使用release/latest_plus_v3_hdmi_capture.bit及现有TD下载流程；需要查看/重编译时用根目录“打开FPGA工程.bat”。
2. STM32打开当前Keil工程，用原ST-Link下载配置编译下载；集中HEX是release/robot_arm_control.hex。六路PWM引脚与原工程相同。
3. 启动本包电脑软件；本地拨码1011进入SORT，1100为远程入口。启用SORT后等待扫脸、回俯视与稳定。
4. OLED依次提示用方块3映射(10,10)、(20,10)、(15,20)、(5,20)、(25,20)cm，每点稳定后自动采集均值，随后移走方块3。
5. 工件静止后确认整批，按实际X升序、X相同时Y升序抓取；圆形奇数左放、偶数右放，方形跳过。
6. 抓取期间冻结目标，结束闭爪回默认并等待后再接收新目标。五点映射只在RAM，复位后重做。

OLED固定单页展示。动作使用五次平滑曲线，CH5最后下降、最先抬起；本包采用连续抓放及开1000/闭1500μs设置。原标定模型的局部空间误差记录仍保留，实际落点与抓放效果沿用机械臂工程中的验收说明。
