# 2026-10-28 五点标定与夹爪更新

本次原位更新robot_arm_control，包含用户追加的两个标定点及后续夹爪调整。此后同日已实现连续批次及再次提速，最新动作与时序见docs/连续抓放与再次提速_20261028.md；本文保留本次五点映射说明。

首次像素到实际坐标映射使用方块3，按OLED依次放在以下位置（cm）：

1. (10,10)
2. (20,10)
3. (15,20)
4. (5,20)
5. (25,20)

各点仍先稳定约1秒，再记录至少500ms、至少5个有效包的像素均值，检查源帧推进。完成前三点或前四点不会提前退出，OLED显示MAP 1/5至MAP 5/5，当前实际坐标、实时像素、目标信息和采样状态保持在同一页。

全部五点均值一起做平面仿射最小二乘拟合，不只用前三点。计算先将像素与实际坐标居中，再解二维协方差方程；保留覆盖面积及近共线检查，并拒绝非有限数据与退化映射。完成后仍需移走方块3再开始目标确认。系数在RAM，复位后重做五点映射。原31点cm到PWM模型与真实JSON不变。

用户实测850μs张开已达到机械限位，当前统一恢复原张开1000μs，闭合保持1500μs。默认/左右姿态中的其他舵机值、提速参数、CH5先抬后降顺序、引脚和原下载配置均保留。

离线回归覆盖五点完整采集、第三/四点不提前结束、两新增点分别参与拟合、旋转/反向像素轴、共线与细长/非有限数据拒绝、OLED新增两步及原批次动作。连续化之前的62次指令时序模拟平均21.56秒；这不是实机测量。当前检查结果见tests/results.json，编译/内存与HEX摘要见firmware/build_report.json。没有连接真实串口或自动烧录。
