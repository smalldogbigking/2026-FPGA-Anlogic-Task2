# STM32 当前引脚配置

主控STM32F103C8T6。六路舵机PWM、定时器和50Hz周期完全沿用原工程；新增功能使用PB口，不改原舵机接线。

|原有功能|STM32引脚|定时器通道|用途|
|---|---|---|---|
|舵机1|PA0|TIM2_CH1|夹爪；开1000、闭1500μs（2026-10-28张开恢复原值，闭合不变）|
|舵机2|PA1|TIM2_CH2|夹爪旋转，固定1382μs|
|舵机3|PA2|TIM2_CH3|定位关节|
|舵机4|PA3|TIM2_CH4|定位关节|
|舵机5|PA6|TIM3_CH1|大臂升降，下降最后、抬升最先|
|舵机6|PA7|TIM3_CH2|底座旋转|

|新增功能|STM32引脚|连接|
|---|---|---|
|接收FPGA视觉数据|PB11 / USART3_RX|FPGA GPIOA6、封装T2、GPIOA扩展排针J1第7脚 → PB11；115200、8N1、3.3V TTL|
|SSD1306 OLED时钟|PB6|OLED SCL，软件I²C|
|SSD1306 OLED数据|PB7|OLED SDA，软件I²C，地址0x3C|
|OLED供电|3.3V / GND|OLED VCC / GND，上拉至3.3V|
|可选暂停输入|PB12|按键/开关接PB12与GND；内部上拉，拉低锁定暂停，不接可悬空|
|公共地|GND|FPGA GPIOA排针J1第12或28脚GND、STM32、OLED、舵机电源负极共地|

暂停后松开输入不会自动恢复；释放暂停开关后按开发板RESET复位，复位后重新五点映射。没有使用暂停输入时不需接PB12。

原电脑串口PA9/PA10和上一版额外事件输出PB10现均未使用。不接USB-TTL，不发送电脑日志。PB11只收FPGA，不需要STM32 TX接线。FPGA GPIOA6与STM32 PA6不同，STM32 PA6仍只接舵机5。

|原下载接线|STM32引脚|
|---|---|
|ST-Link SWDIO|PA13|
|ST-Link SWCLK|PA14|
|ST-Link GND|GND|
|目标参考电压|按原ST-Link方案接3.3V参考，不改变原供电方式|

Keil下载方式保持原ST-Link。原工程的Debug、Utilities、Flash算法、SWD、复位、Flash/RAM地址及器件配置已逐项对照；14组配置相同，记录在tests/download_config_check.json。新电脑或新Keil可能自行升级器件包字段，tools/build.py结束时会恢复原交接包设置并再校验。
