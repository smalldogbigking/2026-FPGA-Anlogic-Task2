# 视觉接收与批次策略

FPGA原协议保持：115200 8N1，`A5 5A 01 01 SEQ_LE FRAME_LE COUNT LEN`，其后每目标9字节 `slot,class,shape,digit,x_LE,y_LE,flags`，末2字节CRC16小端。CRC为CCITT-FALSE，初始FFFF，多项式1021，覆盖版本到最后payload。最大4目标、48字节，空心跳12字节。STM32验证范围、长度、CRC、重复槽位和坐标边界。

MCU识别形状码：0未知、1圆、2方、3其他；数字1～5。形状/数字可信时要求flags低3位全部为1。flags bit3是FPGA旧像素工作区，本工程使用五点映射后的实际范围与原模型凸包，不以bit3作为通用坐标门槛。

类别从 `vision_category(shape,digit)` 统一重算，不依赖FPGA class作运动决策：圆奇数1、圆偶数2、方3为3、方1245为4。以后改这里即可改规则；同时修改抓放侧别策略和测试。

在MAP、REMOVE S3、IDLE、CONFIRM中接受新SEQ，检查FRAME_ID推进和通信新鲜度。FRAME_ID是最旧分类ROI源帧，而不是10Hz包计数；故源帧停滞门槛配置为2500ms，链路无包门槛500ms。SEQ推进不能无限延长冻结源帧有效期。恢复通信或源帧重启会重新确认，不延续上次未完成的确认时长。

映射默认点(10,10)/(20,10)/(15,20)/(5,20)/(25,20)cm。唯一有效方块3在10像素半径内稳定1秒且源帧推进后开始采样。至少500ms、5个包并有源帧推进才提交均值。移动/丢失重置本点，多个方块3不采样；两步之间要求标志移动至少45像素。采集五点后，所有均值共同参与最小二乘仿射拟合；覆盖面积过小、点集近共线、数据非有限或实际点不在原空间模型内均拒绝。映射完成要求移走标志，再进入普通确认；正常工作中出现方块3仍只跳过，不抓取。

每包通过全局最近位置配对关联旧目标，不使用slot身份。45px为关联门槛，10px为稳定半径；数字/形状变化、超出稳定半径或消失重置整批静稳计时。每目标至少5次观测、1秒稳定和源帧推进，且全场连续1秒无变化、所有当前目标均确认，才冻结批次。未知标签会阻止半批启动；目标没有稳定前不启动抓取。短暂消失使其失去ready，超过500ms从候选清除，无目标2秒返回空闲。

冻结记录包含平均像素中心、转换后的cm位置、形状、数字、本地类别和处理状态。排序严格实际X升序，X相同时Y升序。原模型凸包外、实际范围0..30/0..26cm外不执行；两目标物理间距小于3cm时阻止相应抓取，提示`!`。这是固定工位的邻近门槛，不是通用避障。

PICK/HOME/SETTLE期间视觉包只被消耗并计为忽略，不更新任何冻结目标，也不因视觉超时取消锁定任务。串口接收和PWM继续运行；结束后回默认闭爪并等待1秒，丢弃接收缓存和半包，从新包重新确认。因为批次使用已锁定静态位置，抓取时外力移动剩余工件无法被本流程纠正，工件需符合用户约定保持静止。

2026-10-28连续抓放：每件放下、松爪后，CH5先抬到原默认2191μs并完成轨迹和100ms停留，才允许衔接。动作核心根据冻结队列中后续ITEM_WAIT决定是否保持张开；中间SKIP/BLOCKED不算待抓目标。有下一件时直接高位调整其他关节，再让CH5最后下降。最后一件抬臂后，在CH5保持原默认高度时并行回默认/闭爪，省去独立FINAL_CLOSE阶段。若计划的余项意外取消，批次控制器仍须等最终闭爪回默认完成后才进入SETTLE。暂停清除衔接许可且不自动继续。

完成位置保留抑制记录。重新观察时，该位置需连续被看到为空约1秒才释放，避免旧记录重复抓。方形不进入抓取，在OLED以类别和跳过状态显示。生产固件不连接电脑，不发JSON事件，不保留电脑测试协议；底层事件回调仅用于原生假HAL验证，main传入NULL。PA9、PA10、PB10不占用。

五点映射只建立平面仿射关系，不包含镜头畸变或透视单应性校正。相机应固定俯视同一平面；2026-10-28按用户要求由三点扩为五点，使用全部五点均值做最小二乘拟合，映射系数不写Flash，复位重新标定。
