# 单页显示与状态流转

OLED 使用四针 I²C SSD1306 0x3C，PB6/PB7，5×7字符加间隔组成6×8字格。全部状态固定8行；四目标始终可以在同一屏上看到。驱动每次只传32字节，分段刷新，串口中断与硬件PWM不因整屏传输阻塞。无屏、NACK或SCL被拉低均有有界退出和重试，不阻塞机械臂控制循环。

|状态|含义|进入与退出|
|---|---|---|
|HOME|默认闭爪回位|上电或明确恢复；完成回位后去MAP或IDLE|
|MAP|五点像素映射|等待唯一有效方块3，先稳定再采样；全部五点完成后最小二乘拟合|
|REMOVE S3|移走标定标志|连续稳定看不到标志后转IDLE|
|IDLE|空闲、默认闭爪|无目标、只有不抓目标，或视觉失效；有新/变化目标转CONFIRM|
|CONFIRM|场景稳定及目标确认|每目标确认且全场静止后冻结；无目标长时间返回IDLE|
|PICK|整批锁定抓放|不采纳视觉；逐件完成，保持原冻结坐标及标签|
|SETTLE|整批后闭爪默认等待|等待1秒，清接收缓存，转IDLE重新观察|
|STOP|锁定暂停|保留当前PWM；松开硬件暂停不自动恢复，按RESET复位|

映射屏：第1行步骤，第2行真实cm点，第3行最新像素中心，第4行接收到的形状码S/数字D/类别C，第5行稳定进度，第6行采样毫秒和样本数，第7行采样均值，第8行操作提示。这里的`S2`是串口形状码2，即方形，不是“第2个目标”。未检测到目标显示 `TARGET --- WAIT`。

确认屏：第1行当前目标数N、已确认数OK；第2行坐标单位；第3～6行四个目标；第7行等待稳定/标签等原因；第8行串口状态和错误计数。`?`表示该目标尚未完成稳定及标签确认，`+`表示已确认。

抓取屏：第1行冻结总数和已抓数；第2行当前目标、形状、数字、分类及左右；第3～6行所有冻结目标，坐标cm；第7行动作阶段；第8行 `RX IGNORED / LOCKED`。显示`>`正在抓，`*`完成，`+`待抓，`-`标定/方形不抓，`!`越界或间距不足。

空闲时若保留上一批完成信息，第1行用 `NOW` 显示当前观察数量，第2行明确标为 `LAST BATCH`，下方为上批记录，不将上批目标数当作当前目标数。数字0和类别0表示尚未确认，并非支持识别数字0。

动作阶段：`OPEN_HOME`首次开爪，`TARGET_OTHERS`在CH5原默认高度定位，`TARGET_CH5`最后下降，`GRIP_CLOSE`闭爪，`CARRY_HOME_CH5`先抬臂，`CARRY_HOME_OTHERS`带物收臂，`DROP_TURN`转底座，`DROP_EXTEND`伸出，`DROP_CH5`下降，`GRIP_OPEN`松爪，`RETURN_CH5`先抬臂。有下一件时直接回到`TARGET_OTHERS`；最后一件进入`RETURN_HOME_CLOSED`，在高位回默认并同时闭爪。中间不再显示默认回位或反复闭爪/开爪，`FINAL_CLOSE`独立步骤已合并。`NEXT_READY`为动作核心短暂的高位开爪交接状态，OLED继续显示整批PICK。

构建中保存的 `tests/oled_*.png` 是直接用同一固件字库和帧缓冲离线生成的像素预览，不是实机照片。固件不分页、不自动轮播；不同状态切换时更新该状态所需信息。
