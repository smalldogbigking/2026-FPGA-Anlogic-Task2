# 连续抓放与再次提速 · 2026-10-28

当前robot_arm_control已按用户要求将批内动作连续化。原五点映射、目标确认与冻结队列、X/Y排序、圆奇左/偶右、方形跳过、开1000/闭1500μs及原空间模型保留。

## 当前动作

首次从默认闭爪开始，开爪、在CH5原默认高度定位、最后下降CH5、闭爪抓取。带物先抬CH5、收臂，再转向对应分类姿态、伸出、最后降CH5放下并松爪。

放下后先单独将CH5抬到原默认2191μs，等待本段轨迹及100ms停留结束。队列还有可抓目标时保持张开，直接将CH2/3/4/6移到下一目标的标定PWM，保持CH5不下降；其他关节到达指令终点后才调整CH5到抓取位置。中间不再回默认、不闭爪、不重复开爪。SKIP和BLOCKED目标不会延长连续任务。

最后一件放下并抬臂后，CH5保持上述高度，其他关节回默认的同时闭爪，省去独立FINAL_CLOSE段。完全回默认闭爪后才进入原1秒批末等待，再清接收缓存并重新观察。即使原计划余项意外被取消，也会先完成最终回位。暂停保持当前PWM，清除连续衔接许可，不自动续抓。

横移高度沿用原默认姿态的CH5值；这是PWM时序保护，无末端位置反馈或几何避障检测。当前不能将五次指令曲线与实际末端位置或实测到位等同。

## 再次提速

|通道|峰值速度前→现（μs/s）|峰值加速度前→现（μs/s²）|
|---|---:|---:|
|CH1|1500→1700|8000→9000|
|CH2（仍固定1382）|1000→1100|4500→5000|
|CH3|1000→1200|4200→5000|
|CH4|900→1050|3600→4200|
|CH5|700→850|2200→2800|
|CH6|650→800|2000→2500|

定位段最低请求400→300ms，夹爪450→400ms，具体仍由各关节速度/加速度限制延长。普通定位后停留100→60ms，CH5和独立底座转向仍100ms，夹爪300→250ms。最终回位并行闭爪后仍保留250ms停留。各段继续五次平滑加减速，不加PID。

## 验证

原生假HAL回归覆盖48种整批/跳过/阻止与左右组合、抬臂/交接/下一目标横移时暂停、无效下一点及余项意外取消。连续基准覆盖31组真实模型位置和16种左右组合，共496个四目标批次、1984次抓放，检查每次高位开爪交接与最终默认闭爪。

同一基准程序修改前平均86.25秒/批，当前63.91秒/批，耗时减少25.90%；独立单目标62次平均由上版21.56秒降为17.44秒。以上是10ms步进的PWM指令时间，不含确认和批末等待，不是实机测量。报告为tests/results.json、tests/continuous_comparison.json及tests/motion_comparison.json。
